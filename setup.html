A calm first run

Get from “I want better jobs” to your first shortlist.

FTJA starts in your AI coding agent because that is where it can create a private local workspace for your files. After that, the browser becomes your control room.

01

Open a new Claude Code or Codex session

Copy this once. Paste it into a fresh session. You do not need to write a path, edit JSON, or install a package yourself.

Clone https://github.com/TaegyuJEONG/ftja.git into a new local FTJA workspace, open the generated folder in this session, and run the FTJA setup skill. Start the local web onboarding. Do not guess my preferences.
02

Let FTJA turn your background into a working profile

In the local web onboarding, choose your resume, portfolio, or other relevant files. The agent reads them and prepares a concise profile summary instead of sending the raw files through every job review.

  • Profile What you have built, shipped, and learned
  • Search Suggested LinkedIn roles, locations, and concrete keywords
  • Standard Your yes signals, preferences, and dealbreakers
03

Confirm the judgment before the first run

FTJA writes a reviewable rubric and search criteria. Look at the Pipeline tab, edit anything that is wrong, then run manually once. This gives you a real baseline before scheduling.

The first release searches public LinkedIn postings. It does not ask for your LinkedIn password.
04

Review, decide, and teach carefully

Results include the role, evidence, and reasoning. Mark apply or skip and add why. On a later interactive run, FTJA can propose a change to your rubric for your approval. It never silently changes your standard.

Copy the setup prompt again
After the first manual run works, scheduling the same pipeline daily is the next step.
